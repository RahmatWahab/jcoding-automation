# Implementation roadmap — based on the 2026-10-18 audit

The working tree already contains substantial autonomy, intent and containment code. This plan hardens and verifies that work before adding broad new agent features. Keep changes in a separate branch/worktree or otherwise preserve the current uncommitted tree; do not infer that current edits are safe to discard. Roll out through offline tests, disposable repositories and dry-run/canary settings. No implementation is performed in this audit.

## Smallest useful first implementation

Triage the current release-gate failures without weakening the contracts, then restore a green `autonomyReleaseGate`. This is the smallest useful first step because the existing system already has intent capture, structured file operations, budgets, state recovery and delivery guards, but the current tree has neither a passing release gate nor real-task evidence. Start with `EngineResultTest`, `StateRecoveryTest`, `WorkflowE2EHarnessTest`, `OpenPrRecoveryE2ETest` and `WorkflowOrchestratorIntegrationTest`; the current run produced 19 JUnit failures plus 20 Checkstyle violations.

## First three implementation tasks

1. **Restore the offline gate.** Inspect XML and Checkstyle reports; fix behavior or update obsolete test expectations only when the intended contract is documented. Acceptance: `./gradlew --no-daemon autonomyReleaseGate` exits 0, runs all test and shell-fixture tasks, and produces its release receipt; no skipped scenario is counted as success.
2. **Test residual isolation and file-application races.** Add tests for broad/symlinked `runtime_read_paths`, concurrent path substitution during `WorkerToolBoundary.apply`, process-tree cancellation, and native-isolation rejection for unattended work. Acceptance: sensitive roots are rejected, stale path/source preconditions produce no write, and canceled descendants terminate within the configured bound.
3. **Centralize goal lifecycle and authenticate local intake.** Refactor `GoalContract` state changes and `LocalRequestWorkflow`/`LocalRequestGitHub` actor handling; retain SQLite revision/CAS semantics. Acceptance: every amendment is bound to authenticated actor + prior revision, illegal transitions fail closed, stale state cannot overwrite newer intent, and cancellation/resumption behavior is covered through restart tests.
